# radarGun

Repo Plan:
- Display code for a ESP 32 radar gun
- Connect radar readings with a local app

Overall Plan:
- Build a radar gun that uses the doppler effect to measure speeds
- Build the whole product for less that $100 (cheaper than the cheapest radar guns)
- Have accuracy readings that are ± 2 mph
- Document learning journey


Key Hardware Components:

- ESP32-WROOM
- CDM324 24GHz Microwave Sensor Module
- LM358N Operational Amplifier
- LM393 Comparator
- LCD1602 Display Module
